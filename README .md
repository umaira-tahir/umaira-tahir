## 🚀 Featured Projects

### 🧠 AI Engineering

- 👕 **[Fashion-MNIST CNN Classifier](https://github.com/umaira-tahir/fashion-mnist-cnn-classifier)**: Custom CNN built with PyTorch to classify clothing images, using batch normalization for stable training.

- 🗑️ **[Waste Classification with Transfer Learning](https://github.com/umaira-tahir/waste-classifier-transfer-learning)**: Organic vs Recyclable image classifier using VGG16 transfer learning and fine-tuning in TensorFlow/Keras.

- 🌧️ **[Rainfall Prediction: Australia Weather](https://github.com/umaira-tahir/rainfall-prediction-aus-weather)**: Next-day rainfall prediction with a Scikit-learn pipeline (Random Forest, Logistic Regression) tuned with GridSearchCV.

- ✈️ **[Aircraft Damage Classification & Captioning](https://github.com/umaira-tahir/aircraft-damage-classifier)**: Classifies aircraft damage (dent vs crack) with a fine-tuned VGG16 and generates natural-language captions using the BLIP vision-language model.

- 🎮 **[League of Legends Match Predictor](https://github.com/umaira-tahir/league-of-legends-match-predictor)**: Logistic regression in PyTorch with L2 regularization, hyperparameter tuning and feature importance analysis.

### 🤖 Agentic AI

- 🎪 **[Multi-Workflow Presales AI Agent System](https://github.com/umaira-tahir/presales-ai-agent-system)**: End-to-end autonomous presales system built with n8n, Google Gemini API, custom sub-workflows and Gmail integration.
