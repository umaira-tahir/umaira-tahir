## 🚀 Featured Projects

### 🧠 AI Engineering

- 👕 **[Fashion-MNIST CNN Classifier](https://github.com/umaira-tahir/fashion-mnist-cnn-classifier)** — Custom Convolutional Neural Network built with PyTorch to classify clothing images, featuring batch normalization for improved training stability.

- 🗑️ **[Waste Classification Using Transfer Learning & Fine-Tuning](https://github.com/umaira-tahir/waste-classifier-transfer-learning)** — Image classifier (Organic vs Recyclable) built with VGG16 transfer learning and fine-tuning in TensorFlow/Keras.

- 🌧️ **[Rainfall Prediction — Australia Weather Dataset](https://github.com/umaira-tahir/rainfall-prediction-aus-weather)** — Predicts next-day rainfall using a Scikit-learn pipeline with Random Forest and Logistic Regression classifiers, tuned with GridSearchCV.

- ✈️ **[Aircraft Damage Classification & Captioning](https://github.com/umaira-tahir/aircraft-damage-classifier)** — Classifies aircraft damage (dent vs crack) using a fine-tuned VGG16 model, with natural-language captions generated via the BLIP vision-language model.

- 🎮 **[League of Legends Match Predictor](https://github.com/umaira-tahir/league-of-legends-match-predictor)** — Logistic regression model built in PyTorch to predict match outcomes, with L2 regularization, hyperparameter tuning, and feature importance analysis.

### 🤖 Agentic AI
